# BandMate

Bandmate is intended as a social network for musicians. A place for local bands, venues, performers and producers to socialize and connect all for the creation of music. 

## Features
- Band to band connections
- Player audition events
- Production assistance
- Booking and B2B planning
- Collaborations
- Professional guides
- Public event calendars

## Goals
1. Connect musicians and venues to keep the spirit of live music alive.
2. Offer resources and help for new musicians.
3. Provide a technical toolkit for digital collaboration and production.
4. Become the central social hangout for musicians, music venues, and music lovers to spend their time.
